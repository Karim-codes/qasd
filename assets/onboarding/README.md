# Qasd welcome illustrations

Original assets generated for Qasd on 17 October 2026 with OpenAI image generation:

- `makkah-paper.png`: a simplified paper-and-ink impression of the Ka'bah, colonnades and minarets, using Qasd's navy, cream, forest and gold palette. Gold decoration was simplified to remove generated lettering.
- `journey-paper.png`: an open blank guide, travel bag and architectural archway in the same visual style.

These are decorative illustrations, not photographs, maps, exact architectural reconstructions or ritual instructions. No third-party onboarding screenshot was used as a product asset. The existing Qasd brand mark is used separately without modification. Both original PNGs are bundled locally so the welcome flow works offline.

Include the welcome screens, illustrations and interactive guide previews in the independent religious-content review. The release fingerprint includes this directory.
