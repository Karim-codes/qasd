# Qasd rebrand and project organisation

The supplied artwork is preserved at `assets/brand/qasd-source.png`. App, adaptive and favicon sizes are generated by `npm run brand:assets`. Expo config, the existing local iOS display name/icon catalog, welcome screens and Settings use Qasd. Native changes require a new build. Bundle ID, EAS project slug/ID and legacy persistence keys remain stable for continuity; existing provider names and parser patterns remain literal.

App source now lives under `src/`, with `@/` pointing there. Routes live in `src/app/`, shared UI in `src/components/`, and flight-specific UI in `src/features/flights/`. The custom PDF module remains at root `modules/` for Expo autolinking. Test imports and the PDF module import were updated. Generated route declarations were refreshed for the new route root.

Open `Qasd.code-workspace` for the new Explorer name. Generated folders are hidden, not deleted. Personal itinerary exports and notes were moved into ignored `.local/`; starter assets and the reset script were archived under `docs/archive/`. README documents the working structure and commands.

Flight cards use paper and sage surfaces, a Qasd ribbon, perforations, side cutouts and a passenger stub. Real flight numbers and booking references are shown when available; airport codes are only used when present in the saved city string. Departure and arrival each show their own dates and editable times. Cards are labelled travel itineraries, not issued boarding passes.

Validation: TypeScript passed; web export found all 29 routes; a focused 390px browser check found no runtime exceptions or page-width overflow; all three existing storage compatibility tests passed. No native build or full regression suite was run. Previews: `previews/qasd-flight-tickets.png` and `previews/qasd-brand.png`.

## Welcome motion and journey selection

The welcome ayah now arrives in a calm sequence: the card lifts into place, the Arabic ayah fades upward, a gold rule opens across the card, then the translation and source appear. The sequence respects the device's Reduce Motion setting.

Umrah and Hajj cards now behave as a selection. Tapping either card changes the visual emphasis with a spring transition: the selected card becomes cream and the other returns to navy. Card taps remain on the selection screen; only the labelled “Plan my Umrah” and “Plan my Hajj” buttons navigate.

The splash uses a standalone transparent gold Qasd mark on the navy background at 148 points instead of nesting the complete rounded app icon inside the splash. The current iOS storyboard and image catalog are refreshed, and future Expo native generation uses the same asset. The workspace-bound mark is `assets/brand/qasd-mark.png`.

The splash mark was produced with the built-in image generation tool as a background-extraction edit of the supplied Qasd icon.
